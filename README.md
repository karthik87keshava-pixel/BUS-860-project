# DriveTally (working name)

A website for comparing the full cost of getting and running up to 4 cars in Alberta — loan, lease or cash — over 1 to 8 years.

Built for the UAlberta EMBA course BUS 860 (Managing Intelligence).

## Where things are

- `docs/BUILD_PROMPT.md` — the team's original brief.
- `docs/PLAN.md` — the build plan and a sketch of the compare page.
- `DECISIONS.md` — every assumption, data source and design choice, with dates.
